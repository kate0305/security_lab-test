# Тестовое задание — Форма создания пользователя

# Запуск проекта

Установка зависимостей:

```
npm install
```

Запуск dev сервера:

```
npm run dev
```

---

# Технологический стек

- **Next.js 16 (App Router)**
- **TypeScript**
- **TailwindCSS**
- **shadcn/ui**
- **react-hook-form**
- **zod**

Архитектура проекта построена на основе **FSD**.
